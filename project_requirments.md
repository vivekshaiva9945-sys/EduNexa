1. # Project Name: EduNexa
   **Overview:** A scalable, role-based college management system.

## Core User Roles & Features

* **Admin Portal:**
  * View average college-wide student attendance.
  * Post global announcements to the Notice Board.
  * View faculty attendance records.

* **Faculty Portal:**
  * Take daily attendance for assigned classes.
  * View personal faculty teaching timetable.
  * View average student attendance for their specific classes.
  * Assign and upload marks for student tests.
  * View the global Notice Board.

* **Student Portal:**
  * View personal attendance records.
  * View personal class timetable.
  * Check test marks and academic progress.
  * View list of upcoming holidays and exam dates.
  * View the global Notice Board.
